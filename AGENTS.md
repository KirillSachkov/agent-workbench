# agent-workbench

Проект на стадии seed: полного харнесса ещё нет. Перед работой прочитай `docs/brief.md` и
`docs/decisions.md`.

- Задачи и спецификации живут в GitHub Issues этого репозитория (`KirillSachkov/agent-workbench`).
- Исследования — датированные заметки в `docs/research/` с источником у каждого утверждения.
- Решения владельца записываются в `docs/decisions.md` с датой.
- Этапы (идея → спецификация → нарезка → реализация) запускает владелец; агент не связывает их сам.
- Репозиторий публичный: не клади сюда личные пути, секреты, данные участников и содержимое
  приватных репозиториев.
- Отвечай владельцу по-русски; код, команды и устоявшиеся термины оставляй на английском.
